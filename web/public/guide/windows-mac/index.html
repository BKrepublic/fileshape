Windows / MacでEPUBを読む方法

パソコンでは、EPUBリーダーを2種類ほど用意しておくと、読むだけでなく変換結果の確認もしやすくなります。

WindowsではEPUB 3対応リーダーで開きます

たとえばThorium Readerは、Windows、macOS、Linuxで使える無料のオープンソースEPUBリーダーです。FileShapeでEPUBを保存したら、リーダーへ読み込んで開きます。

MacではApple Booksでも読めます

MacではApple BooksへEPUBを追加して読めます。別の表示エンジンでも確認したいときは、Thorium Readerなどを併用すると原因を切り分けやすくなります。

変換結果の確認には、大きな画面が便利です

本文の順番、画像の位置、見出し、ルビ、ページをまたぐ段落を見比べるなら、スマートフォンよりパソコンのほうが確認しやすくなります。同じ箇所が複数のリーダーで崩れるならEPUB側、片方だけならリーダー側の表示差を疑えます。

最初に確認する5項目

  1. 最初の数ページを問題なく読めるか
  2. 縦書き・横書きが意図した向きになっているか
  3. 見出しと本文が自然な順番で並んでいるか
  4. ルビや画像が正しい位置に付いているか
  5. 文字サイズを変えても読み続けられるか
