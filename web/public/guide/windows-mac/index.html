Windows / MacでEPUBを読む方法

パソコンでは、変換したEPUBをデスクトップ向けリーダーで開くと、本文構造や表示を確認しやすくなります。

Windows

EPUB 3に対応したデスクトップリーダーを使います。たとえばThorium ReaderはWindows、macOS、Linuxに対応した無料のオープンソースEPUBリーダーで、EPUB 2/3を扱えます。FileShapeの変換結果を確認するときは、EPUBファイルを保存してからリーダーで開きます。

Mac

MacではApple BooksへEPUBを読み込むことができます。Booksの「ファイル」から読み込むか、EPUBをライブラリへ追加して開きます。別の実装でも確認したい場合はThorium ReaderなどのEPUB 3対応リーダーを併用すると切り分けに役立ちます。

変換確認にパソコンが向いている理由

スマートフォンより画面が広いため、本文の読書順、画像位置、見出し、ルビ、ページ境界での段落接続などを見比べやすいです。同じEPUBを2種類のリーダーで開き、同じ箇所が同じように崩れるならEPUB側、片方だけならリーダー側の表示差である可能性が高くなります。

確認する順番

  1. 最初の数ページが読めるか
  2. 縦書き・横書きが意図通りか
  3. 見出しや本文の順番が自然か
  4. ルビと画像が本文に追従しているか
  5. 文字サイズを変えても読めるか
