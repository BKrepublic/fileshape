GUIDE / LOCAL PROCESSING

ブラウザ内ローカル変換とは

FileShapeは、PDF本文を変換サーバーへ送らず、利用している端末のブラウザ内でEPUBを作ります。

PDFを選んだ後も、変換処理は端末内です

ブラウザがPDFを読み込み、別の処理領域でPDF解析とEPUB生成を行います。この仕組みをWeb Workerと呼びます。変換のためにPDF本文をFileShapeのサーバーへアップロードする構成にはしていません。

サーバーへPDF本文を預けなくて済みます

  • 変換用サーバーへPDF本文を送らずに済む
  • 変換用ファイルのサーバー保存期間を気にしなくてよい
  • サーバー側で文書内容を解析する必要がない

その代わり、変換に使える処理能力とメモリは利用中の端末やブラウザに左右されます。

大きさより、中身が重いPDFもあります

13MBなら軽く、100MBなら重いとは限りません。ページ数、文字数、画像、フォント、描画命令が多いPDFは、ファイル容量が小さくても大きなメモリを使うことがあります。特に数千ページのPDFでは、スマートフォンのほうが先に限界へ達しやすくなります。

同じ端末でも、ブラウザによって限界が違います

Chrome系とFirefox系では、JavaScriptの実行環境やメモリ管理などが異なります。同じPDFでも処理時間や安定して扱えるページ数が同じとは限りません。長時間止まったように見えたり、タブが再読み込みされたりする場合は、メモリ不足の可能性があります。

「ローカル変換」は、通信が一切ないという意味ではありません

端末内で処理するのはPDF本文の変換です。サイト自体を表示するためのHTMLやJavaScriptの配信、広告などでは通常のWeb通信が発生します。詳しくはプライバシーポリシーと広告・アフィリエイトポリシーをご確認ください。
